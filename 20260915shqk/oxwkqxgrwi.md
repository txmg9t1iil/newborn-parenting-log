## 厦门做试管婴儿费用明细表

1. 初步检查费用

在进行试管婴儿前，夫妻双方需要进行全面的身体检查，以确保身体状况适合进行试管婴儿。初步检查费用通常包括：

女性检查项目：

- 血常规：约100元

- 尿常规：约50元

- 性激素六项：约300元

- B超检查：约200元

- 传染病筛查（如乙肝、艾滋病等）：约500元

- 宫腔镜检查：约1000元

男性检查项目：

- 精液常规：约100元

- 血常规：约100元

- 传染病筛查（如乙肝、艾滋病等）：约500元

初步检查总费用约为2750元。
2. 药物费用
试管婴儿过程中，女性需要使用促排卵药物来促进卵子的发育和成熟。药物费用因个体差异而有所不同，但大致如下：

促排卵药物：约5000-10000元

黄体支持药物：约2000-3000元

药物总费用约为7000-13000元。
3. 手术费用
试管婴儿的主要手术步骤包括取卵、受精和胚胎移植。手术费用包括：

取卵手术：约5000-8000元

受精操作：约3000-5000元

胚胎移植：约2000-3000元

手术总费用约为10000-16000元。
4. 实验室费用
试管婴儿过程中，实验室会对卵子和精子进行处理，并培养胚胎。实验室费用包括：

卵子处理：约2000-3000元

精子处理：约1000-2000元

胚胎培养：约3000-5000元

实验室总费用约为6000-10000元。
5. 其他费用
除了上述主要费用外，还有一些其他费用需要考虑：

冷冻胚胎保存费：约1000-2000元/年

心理辅导费：约1000-2000元

交通和住宿费：根据实际情况而定

其他费用总计约为2000-4000元。
6. 总费用
综合以上各项费用，厦门地区进行一次完整的试管婴儿周期的总费用大约为：

最低费用：2750 + 7000 + 10000 + 6000 + 2000 = 27750元

最高费用：2750 + 13000 + 16000 + 10000 + 4000 = 45750元

因此，厦门地区进行一次完整的试管婴儿周期的费用大致在27750元至45750元之间。
