# 为什么外国都买科兴疫苗而不用国药疫苗？

> 更新时间：2026-09-18 (UTC+8)

我发现最近跟我们关系比较好的国家都在买我们国家的科兴疫苗，但是国内接种的话，大多都是国药的疫苗，科兴的较少。我朋友说是为了避免疫苗在哪些国家身体内产生抗体，这样我们打科兴疫苗就没有用，所以科兴大多出口，而国药主要对内接种。但我感觉有点扯，所以问问大家为什么外国都买科兴疫苗而不用国药疫苗？ 
查看全部内容

其实国外不仅只购买科兴疫苗也有购买国药疫苗的，只是科兴新冠疫苗出口数较多而已，所以才会产生国外都用科兴疫苗不用国药疫苗的错觉。至于科兴疫苗为什么出口数更多，这主要是因为科兴的国外第一个研发新冠疫苗的厂商，并且其临床试验数据也非常不错。虽然在每个国家预防新冠肺炎感染的有效率不一样，但其保护效力都可以达到50%以上，并且还能100%预防重症，所以不少国家都会优先选择进口科兴疫苗。

科兴灭活疫苗是由北京科兴中维生物技术有限公司（Sinovac）联合多家合作单位开发的灭活疫苗CoronaVac。该疫苗目前在国际上大受欢迎，主要是因为：

- 1. 科兴是在国外最早研发及临床试验的，所以国外会普遍使用科兴；
- 2. 世界卫生组织于4月26日和5月3日分别开启对国药疫苗和科兴疫苗的认证过程，通过审核评估，5月7日世卫组织正式为国药疫苗颁发了紧急使用认证；
- 3. 巴西科兴疫苗预防所有新冠病例的保护效力为50.7％，预防中症和重症的保护效力分别是83.7％和100％；
- 4. 智利科兴疫苗预防新冠肺炎感染的有效率为67％，住院病例预防率为85％，重症病例预防率为89％，感染死亡预防率为80％；
- 5. 根据各国科兴疫苗效力研究结果显示，该疫苗可预防51%的接种者出现疾病症状，并预防100%的研究人群出现严重新冠病毒病和住院治疗。
截止目前，至少有34个国家紧急使用了科兴新冠疫苗，其中包括印度尼西亚、土耳其、巴西、智利、哥伦比亚、乌拉圭、老挝、墨西哥、泰国、马来西亚等国家。
