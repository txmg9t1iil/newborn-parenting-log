# 一觉醒来，14岁少女脚踝烫出了一颗“乒乓球”

> 更新时间：2026-09-16 (UTC+8)

连日来的低温天气，让14岁的初中女生小高手脚寒凉，夜晚难以入睡。1月4日晚，她把一个电暖宝放在脚踝的位置取暖。第二天一早醒来，却发现左脚脚踝疼痛，居然被烫出了一颗乒乓球大小的水泡。

脚踝乒乓球大小的水泡（患者供图）

5日，小高在妈妈的陪伴下，来到泉州市中医院中医外科就诊。科室主任林连辉主任医师接诊后，立即对烫伤处进行消毒，并把水泡中的液体抽出，涂上烫伤膏。面对一脸郁闷的小高，林主任安慰她，10天左右就可以愈合，不必太过焦虑。

林主任介绍，1月份以来，泉州市中医院中医外科已经接诊了3例因使用电暖宝取暖不当，被烫伤的病人。

电暖宝的温度不高，

为什么会发生烫伤事件呢？

林主任介绍，当人体的局部皮肤长时间与高于人体温度的热源接触时，皮肤的感觉神经末梢会逐渐适应当下温度，也不会引起明显的痛觉。

如果局部皮肤长时间与热源接触并且受到压迫，例如睡觉时把电暖宝贴放在身下，影响局部血液循环，从而使散热减少，热量就会积聚，导致慢性烫伤。

“应该避免电暖宝长时间使用或放在同一位置，更不建议睡觉时使用电暖宝。”林主任建议，患有糖尿病并发周围神经病变的老年患者要避免使用电暖宝，因为该类患者四肢末梢感觉能力下降，对温度敏感性较低，长时间接触电暖宝很容易被烫伤，一旦身上出现破溃伤口，想要愈合是相当困难的。

发生烫伤后，医生提醒

可迅速用冷水冲洗烫伤处20分钟以上。若伤口起水泡，不可自行挑破。若烫伤部位有粘连的衣物，不可擅自移除，应及时就医，以免扩大伤口面积，增加感染风险。
